# FreeRTOS 执行机构组合验证

## 验证目标

该实验只在 `C:\Users\Aupassen\Desktop\功能实验和验证\M0_Templant_FreeRTOS` 中启用，验证两组组合动作：

1. 左侧 MG680 减速电机和 yaw 步进轴同时运动。
2. 左右 MG680 减速电机和 yaw、pitch 两个步进轴同时运动。

## 默认流程

1. 上电等待 3 秒，给操作者留出断电时间。
2. 使能 yaw 轴并等待 200 ms。
3. 左轮目标为 `250 mm/s`，右轮为 `0 mm/s`；同时向 yaw 轴发送 `30 RPM、800 pulse` 的位置命令。
4. 运行 1.5 秒后两轮停车，再等待 1.5 秒。
5. 使能 pitch 轴并等待 200 ms。
6. 左右轮均为 `250 mm/s`；紧接着向 yaw、pitch 发送相同的位置命令。
7. 运行 1.5 秒后，保留 3 秒两轴保持力；之后两轮停车并失能 yaw、pitch。


位置命令的“到位”回帧仍会记录在调试快照中，但不作为阶段切换的硬条件。这使得在 MCU RX 未接或驱动器未开启主动到位回帧时，也能完成发送端与执行机构的功能验证。

UART 帧按 yaw、pitch 顺序发送，两个步进轴的启动间隔约为若干毫秒，属于任务级近同步，并非驱动器硬件同步触发。

## 集中配置

- 实验参数：`Component/config/actuator_validation_config.h`
- 两轴串口与地址：`Component/config/stepper_uart_config.h`
- yaw 和 pitch 驱动器地址均为 `0x01`，由两路独立 UART 区分设备。
- 当前假设 `3200 pulse/rev`，因此 `800 pulse` 约为四分之一圈。
- yaw、pitch 默认均使用 CW；若机械正方向不一致，只修改 `actuator_validation.c` 中对应轴方向。

将 `ACTUATOR_VALIDATION_ENABLED` 改为 `0` 后，组合验证任务不再创建，原来的 yaw 按键任务恢复创建。

## 状态观察

调试器可持续观察 `g_actuator_validation_debug`：它记录阶段、yaw/pitch 使能状态、实际发送的命令数、发送结果和响应码。阶段依次为 `WAITING`、`STAGE_LEFT_AND_YAW`、`INTER_STAGE_STOP`、`STAGE_ALL`、`STAGE_ALL_HOLD`、`FINISHED`；任一命令入队失败则进入 `ERROR` 并安全停止。

## 实机前检查

- yaw 使用 UART2（PA23 TX、PA24 RX），pitch 使用 UART1（PB6 TX、PB7 RX）。
- 确认 yaw、pitch 机械行程允许四分之一圈；存在硬限位时先降低脉冲数。
- 将车轮架空，避免第一轮测试时小车冲出工作台。
- 确认两路均为 115200 8N1，MCU TX 交叉连接驱动器 RX，并分别共地。
- 当前只完成构建验证，尚未烧录执行实机动作。
